# Conversor de extratos PDF para Excel

Página que converte extratos bancários em PDF (Banco do Brasil, Itaú, Bradesco, Caixa, Santander, Nubank, Inter, Sicoob, Sicredi, Mercado Pago e outros) em planilha Excel, com conferência de saldo linha a linha.

- A conversão roda **no navegador** de quem usa: o PDF e os dados do extrato não são enviados a nenhum servidor.
- Detecta o banco automaticamente ou deixa escolher na lista.
- Aceita PDF com senha.
- O Excel tem as abas Extrato, Resumo e Linhas não importadas, com valores no formato brasileiro (1.234,56).

**Usar:** abra o link do GitHub Pages deste repositório.
